# Electrical Work Pricing Engine

An object-oriented pricing engine for technical and electrical works.

This project calculates project costs, recommended sale prices, expected profit and negotiation margins based on materials, labor, equipment, location, risk and profit strategy.

## Main goal

The goal of this project is to practice Object-Oriented Programming and the Strategy Design Pattern using a realistic business case.

## Current status

Project definition and functional specification in progress.

## Planned features

- Material cost calculation
- Labor cost calculation
- Equipment and machine cost calculation
- Location-based pricing
- Risk and complexity factors
- Profit margin analysis
- Negotiation margin calculation
- Strategy Pattern implementation
- Unit testing

## Design patterns planned

- Strategy Pattern
- Factory Method
- Repository Pattern
- Dependency Injection
